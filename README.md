# Classroom Cricket

The desk game every Indian student played: a hardcover register for a bat, a classmate's eraser for a ball. Time your swing for sixes, hide when Ma'am's footsteps reach the door, and try not to break the fan before the bell.

**Play:** https://rohitp97.github.io/classroom-cricket/

- Space / tap: swing
- H / Down / HIDE button: act innocent

`index.html` is the source (it's also published as a Claude artifact, which adds the `<html>`/`<head>` shell). Run `sh build.sh` to regenerate the standalone page in `docs/`, which GitHub Pages serves.
